⏳ Countdown Timer

A clean, responsive, and user-friendly Countdown Timer built using HTML5, CSS3, and Vanilla JavaScript. This project allows users to count down to a specific date and time with a live display of days, hours, minutes, and seconds.

🌐 Live Demo

Live Website: https://wadityasingh.github.io/Countdown-Timer-Day-13./


📌 About the Project

The Countdown Timer is a frontend web development project created as part of the Veda Technology Internship, Day 13 task.

The application calculates the time remaining until a selected target date and updates the countdown every second. It provides a simple interface that makes tracking upcoming events, deadlines, birthdays, and important occasions easy.

✨ Features

- Live Countdown: Displays days, hours, minutes, and seconds in real time.
- Custom Target Date: Allows users to select a future date and time.
- Automatic Updates: Refreshes the countdown every second.
- Input Validation: Handles empty, invalid, and past dates.
- Reset Functionality: Resets the timer when required.
- Completion Message: Displays a message when the countdown reaches zero.
- Responsive Design: Works on mobile phones, tablets, and desktop screens.
- Clean User Interface: Minimal white design with readable text and clear controls.

🛠️ Technologies Used

- HTML5: Structure and semantic elements.
- CSS3: Styling, layout, and responsive design.
- JavaScript: Countdown calculations, date validation, and DOM updates.

⚙️ How to Run Locally

1. Clone the repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder.

3. Open "index.html" in your web browser.

4. Select a future date and time, then click Start Countdown.

No additional libraries or build tools are required for the standalone HTML, CSS, and JavaScript version.
